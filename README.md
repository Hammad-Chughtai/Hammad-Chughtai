## Selected work

### SENTINEL — Industrial IoT security

A collaborative research prototype I worked on with a friend, exploring how behavioral analysis, deception, and command authorization can work together in industrial environments.

- Uses recent command behavior and policy context to inform approve, deceive, or block decisions.
- Routes uncertain sessions into isolated decoy environments.
- Uses short-lived, HMAC-authenticated capabilities to authorize specific control-system writes and resist replay or payload substitution.
- Explores the architecture through synthetic command sequences and a Modbus/TCP software testbed with OpenPLC.

**Project areas:** OT/IIoT security, behavioral trust scoring, cyber deception, cryptographic authorization.

**Project tools:** Python, scikit-learn, Modbus/TCP, OpenPLC, HMAC-SHA256.

### [LogWatch](https://github.com/Hammad-Chughtai/LogWatch)

An offline investigation tool for AWS CloudTrail, SSH logs, and normalized authentication events.

- Detects distributed account guessing, spray-like activity, and successful logins after repeated failures.
- Flags AWS root console logins explicitly recorded without MFA.
- Produces HTML and JSON reports with traceable evidence.
- Includes 56 automated tests and Windows/Linux CI.

**Project tools:** Python, GitHub Actions, JSON, HTML.

### [ENABLE](https://github.com/Hammad-Chughtai/enable-p7-)

An accessibility project exploring university digital systems and the needs of neurodiverse students.

- Explores barriers in digital learning environments.
- Includes interface options for contrast, text size, reading masks, and read-aloud support.
- Brings together research, mockups, and an interactive web interface.

**Project tools:** HTML, CSS, JavaScript.
